## Handoff notes
**Built.** npm + TypeScript strict + wrangler + Vitest with `@cloudflare/vitest-pool-workers`.
MIT licence chosen 2026-09-22.

- **`wrangler.test.jsonc` is required and not optional.** The `ai` binding forces Wrangler to open a remote proxy session needing Cloudflare auth, which breaks the "clone and `npm test` offline" rule. The test config omits that binding and uses the `replay` backend.
