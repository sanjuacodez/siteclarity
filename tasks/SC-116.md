# SC-116 — Copy prompt, plain-English copy, UI defect fixes

| | |
|---|---|
| Status | DONE |
| Depends on | SC-111, SC-112 |

## Purpose
Make findings usable by a person and by an AI coding agent, and fix defects found after
the UI rework.

## Delivered
- **Copy prompt** — every finding renders a button producing a self-contained instruction: the page URL, the problem, why it matters, what to change, the verbatim quote, and the exact words to replace. Rules in the prompt forbid inventing figures and require a `[TODO: add figure]` placeholder instead, because the receiving agent has no more access to the truth than we do.
- Clipboard with a `textarea`/`execCommand` fallback and a final `window.prompt` so copying still works without clipboard permission.
- **All finding copy rewritten in plain English** — 60 strings across `assemble/checks.ts`, `static/structure/templates.ts`, `static/language/signals.ts`, `assemble/suggest.ts`.
- Fixed the hyphen regex crash (F20), the competing click listener (F21) and CPU test flakiness (F23).

## Notes for whoever works here next
- The copy-prompt handler is **inside Codex's existing delegated click listener**. Do not add a second `document` click listener — it replaces rather than composes in the harness, and a test asserts there is exactly one.
- `__prompts` is a render-time registry indexed by `data-p`. `resetPrompts()` exists for when a report re-renders.
- Writing this feature tripped the documented template-literal trap immediately: `'\n'` became a real newline and broke the script. `docs/UI.md` §1 is accurate — read it.
