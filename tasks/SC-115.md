## Purpose
Make module 1 deployable by a stranger on a free Cloudflare account in minutes.

## Scope — in
- `wrangler deploy` for the Worker; Pages setup for the UI.
- README: what it does, what it explicitly does not do, and the free-tier position stated **above the fold** — free Cloudflare account, no credit card, no API key, Workers AI covers inference within the free daily allowance.
- Self-host guide: fork → Cloudflare account → `wrangler deploy` → done. Include the optional OpenAI-compatible provider configuration for users wanting stronger judgments.
- `SECURITY.md`: SSRF posture, untrusted-content handling, how to report a vulnerability.
- Document the free-tier ceilings honestly: 100k requests/day, 10k neurons/day, and what happens when they are exhausted.
- Release notes stating exactly which of the ten modules exists (one) and which do not (nine).

## Scope — out
No hosted public demo. If one is ever wanted it needs abuse controls and a cost ceiling that
a self-host does not — a separate task.

## Files owned
`README.md`, `SECURITY.md`, `docs/self-hosting.md`, `.github/workflows/deploy.yml`

## Ship gate for module 1
All must hold:
- [ ] Quote verification 100% across the corpus (SC-110, SC-113).
- [ ] Tier 1 and Tier 2 tests green, offline, with no API key.
- [ ] CPU budget met on the largest fixture (SC-114).
- [ ] **The static layer produces useful findings with the LLM fully disabled.** This is the central claim of the free-tier design; verify it by running the tool with no `AI` binding.
- [ ] Prompt-injection fixture does not alter results (SC-109).
- [ ] No score appears anywhere in output or UI (invariant 2).
- [ ] False-negative rate within the threshold set from SC-113's baseline.

## Validation
```
npx wrangler deploy --dry-run
npm run test:all
```
Then deploy to a **fresh, free Cloudflare account** with no card attached, and run a real
analysis end to end. If that account cannot complete the flow, this task is not done.
