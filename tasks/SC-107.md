## Purpose
Deterministic language-level signals for extractability and specificity. Still no LLM.

## Scope — in
- **Hype density**: superlative/marketing lexicon per 100 words ("best", "leading", "world-class", "revolutionary", "seamless", "cutting-edge"). The lexicon is a **committed, reviewed, documented word list** — never model-generated, so results stay reproducible.
- **Specificity proxy**: density of numbers, dates, units, currencies, proper nouns. Vague claims ("dramatically faster") versus checkable ones ("38% faster than v2.1").
- **Anaphora load**: sentence-initial pronouns and unresolved `it`/`this`/`that` — a proxy for passages that cannot stand alone when extracted out of context.
- **Readability**: sentence length distribution and clause depth, reported as observations, never as a grade.
- **Language gate**: read `lang` and sample the text. If the page is not English, return `cannot_assess` for every check in this file with an explicit reason. The lexicons are English-only and must not be applied to other languages.

## Scope — out
No tone or quality judgment — that is SC-109. No structural checks (SC-106).

## Files owned
`src/static/language/**`, `src/static/lexicons/**`

## Acceptance criteria
- Lexicons live in versioned data files with a short rationale comment, not inline in code.
- A non-English fixture yields `cannot_assess` for every check, with a stated reason — and is explicitly **not** reported as a low-quality page.
- Thresholds are named constants with documented rationale, not magic numbers.
- Findings are phrased as observations with evidence, never as grades.
- Within CPU budget on the largest fixture — regex over long documents is the most likely place to breach 10 ms, so measure it here rather than discovering it in SC-114.

## Validation
```
npm test -- static/language
```

## Handoff notes
**Built.** Hype lexicon (grouped by what the word does), anaphora load, vague
quantifiers, sentence length.

- English-gated. An unlabelled page is assumed English; a labelled non-English page returns nothing rather than applying English lexicons.
- Thresholds are named constants with rationale, not magic numbers.
- `long_sentences` considers **paragraphs only** — list items rarely end in a full stop, so the splitter read a whole bullet as one 71-word sentence.
- `MIN_WORDS_FOR_DENSITY = 25`: below that, density measures are noise.
