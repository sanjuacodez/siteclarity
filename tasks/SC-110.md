## Purpose
Enforce invariant 1 — **evidence is never model-authored** — as executable code rather than
intention. The cheapest high-value component in the plan.

## Scope — in
- Resolve every `EvidenceRef.passageId` against the passage store from SC-104 and populate `quote` **from stored text**.
- Verify every resulting quote is a verbatim substring of its passage.
- **Zero tolerance.** A finding failing verification is dropped and logged as an internal error. It is never repaired, never softened, never shipped.
- Normalisation is limited to whitespace collapsing and Unicode NFC. Document precisely what is normalised and why — loose normalisation is how hallucinated evidence slips through, so the rule must be narrow and deliberate.
- Runs in two places: in the pipeline (drops bad findings) and as a build-time test (fails the build).

## Scope — out
No prioritisation (SC-111). No UI.

## Files owned
`src/assemble/verify.ts`

## Acceptance criteria
- A finding referencing a non-existent passage ID is dropped, not rendered.
- A finding whose quote differs from the stored passage by even one word is dropped.
- A hand-crafted fixture with a deliberately fabricated quote **fails the build**. This test must exist, and it must be impossible to pass by editing the fixture.
- Verification runs over the entire fixture corpus at 100% pass.
- Deterministic and CPU-cheap — this runs on every finding.

## Validation
```
npm test -- verify
npm run verify:corpus    # must report 100%, and gate CI
```

## Why this matters
Every competing tool in this space fails exactly here: confident, fabricated evidence. A
deterministic substring check makes that failure mode structurally impossible rather than
merely discouraged. Do not weaken it for convenience.

## Handoff notes

anything that is not a verbatim substring.

- Normalisation is whitespace + NFC only, deliberately narrow. Loose normalisation is how fabricated evidence slips through.
- Largely structural now: Jev returns typed values and cannot emit prose, so there is no path by which a model authors a quote. The gate remains as defence in depth.
- **Not done:** the deliberately-fabricated-quote fixture that must fail the build. Until it exists the gate is asserted but not proven.


**Update:** the gate is now proven, not asserted. `test/unit/quote-gate.test.ts` constructs fabricated, single-word-altered, stitched-from-two-passages, and dangling-reference evidence, and requires every one to be dropped. Also asserts a finding with unverifiable evidence is never emitted at all.
