## Purpose
Make the result readable and shareable without storing anything server-side.

## Scope — in
- Vite + Preact SPA on Cloudflare Pages: URL input, progress, results.
- Findings list ordered by priority, each expandable to show evidence quotes **in context within their section**.
- Section-by-section readiness breakdown — observations, not grades.
- The `limits` block displayed prominently, not buried in a footer.
- Exports: JSON, Markdown, self-contained HTML — generated client-side from the result already in memory.
- **Optional** KV-backed share link, behind a config flag, **off by default**. When enabled, the UI must state that the link is unlisted, not private.
- Responsive to ~400px; light and dark themes.

## Scope — out
No accounts, no history, no server-side storage beyond the optional KV link. No PDF (client
print stylesheet is sufficient; revisit later if asked).

## Files owned
`ui/**`

## Acceptance criteria
- Works with JavaScript-heavy results without blocking the main thread on large pages.
- Every displayed quote is traceable to its passage and section.
- Exports contain the full result including `limits`.
- With the share flag off, no KV write occurs — assert this in a test.
- No score is rendered anywhere, including in any chart or progress indicator (invariant 2).
- Accessible: keyboard navigable, sufficient contrast in both themes.

## Validation
```
npm run dev:ui
npm test -- ui
```
Manually verify against at least three fixture results: a clean page, a poor page, and a
static-only (provider disabled) run.

## Handoff notes

Per-page table with accordion rows for site and list scans.

- **Read `docs/UI.md` §1 before editing.** The UI is a TypeScript template literal, so a single backslash inside a regex is consumed and silently breaks the whole script. This killed the page twice — once shipped to the user.
- `test/unit/dashboard.test.ts` compiles the emitted script with `new Function()`. Never skip it.
- Accordion ids use a module-level counter: a multi-page report calls `renderGroups` once per page, and a per-call index produced eight elements with id `g0`.
