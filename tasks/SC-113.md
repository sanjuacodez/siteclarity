## Purpose
The ground truth everything else is measured against. Revision 1 of the plan had a
calibration gate with nothing to calibrate against; this task removes that gap early.

## Scope — in
- **15–20 frozen HTML snapshots**, committed. Never fetch live sites in tests — live pages change and the test becomes a flake.
- Deliberate coverage: well-structured page; wall-of-prose page; JS-rendered SPA shell; heavy-hype marketing page; page with valid JSON-LD; page with malformed JSON-LD; FAQ page; non-English page; malformed HTML; a page carrying a prompt-injection attempt.
- Hand-labelled expected findings per fixture, with the labelling rationale recorded.
- Calibration harness reporting per-check agreement against the labels.
- Drift report comparing a run to the last recorded baseline.

## Scope — out
No new checks. No changes to check logic — if calibration reveals a check is wrong, that is
a finding for `FINDINGS.md`, not a fix inside this task (`AGENTS.md` §3).

## Files owned
`test/fixtures/html/**`, `test/calibration/**`

## Licensing care
Committing third-party HTML has copyright implications. Prefer pages you own, permissively
licensed pages, or synthetic pages built to exhibit the target characteristic. Where a real
page is genuinely needed, store the minimal extract and record its source and date.

## Acceptance criteria
- Every fixture has: source/provenance, date captured, why it is in the corpus, and expected findings.
- The quote-verification gate passes at 100% across the entire corpus.
- The calibration report distinguishes false positives from false negatives per check.
- Re-running produces identical output (no nondeterminism).

## Validation
```
npm run calibrate
npm run verify:corpus
```
